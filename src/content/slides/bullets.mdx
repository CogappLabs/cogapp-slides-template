## Key points

<Bullets size="lg">
- First point, kept to a single line where possible.
- Second point that carries the main argument.
- Third point, with a **bold** phrase for emphasis.
</Bullets>

<p class="opacity-80">Plain paragraphs sit alongside bullets. A standard markdown list (without the component) renders as a normal disc list instead.</p>
