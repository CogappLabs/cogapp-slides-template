## Key points

A markdown list is all you need.

- First point, kept to a single line where possible.
- Second point that carries the main argument.
- Third point, with a **bold** phrase for emphasis.
  - Nested items work too, at the same size.

Numbered lists keep their numbers.

1. Ordered when sequence matters.
2. Otherwise reach for dashes.
