notes: |
  Images in `src/assets/` go through Astro's `<Image>`: it optimises them,
  emits width and height to stop layout shift, and lazy-loads by default.
  Pass `loading="eager"` when the image is the point of the slide.

  Anything in `public/` is served as-is, so reach for that only when a file
  must keep its exact name and path (a logo, a favicon, a download).
docs:
  - label: Astro images
    href: https://docs.astro.build/en/guides/images/
